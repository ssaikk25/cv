# AI Challenge Stage 1 — детектор области манипуляции на изображении

Решение задачи бинарной сегментации: по одному RGB-изображению предсказать маску
области, которая была изменена (добавлен/удалён объект, инпейнт, локальная правка).
Маска — одноканальный PNG того же размера, что и входное изображение, где 0 — фон,
255 — изменённая область.

## Метрика

Качество оценивается метрикой AIC Score — гармоническим средним двух величин:

- `Dice_pos` — средний Dice по изображениям с изменениями;
- `FPR_neg` — доля чистых изображений, на которых площадь предсказанной маски
  занимает не меньше 1% кадра (такое изображение считается ложной тревогой).

```
Dice_pos = (1 / N_pos) * sum(2 * |P ∩ G| / (|P| + |G| + 1e-6))
FPR_neg  = (1 / N_neg) * sum(1[|P| / (H * W) >= 0.01])
AIC      = 2 * Dice_pos * (1 - FPR_neg) / (Dice_pos + (1 - FPR_neg))
```

Гармоническое среднее жёстко штрафует разбаланс: при нулевом Dice или стопроцентном
FPR итог обнуляется. Поэтому решение оптимизирует обе составляющие одновременно,
а порог бинаризации подбирается по AIC на валидации.

Особенности данных, выявленные при анализе:

1. 103 699 строк; оригинал (`orgl_img_path`) заполнен только у 42 530 строк.
2. Маски переиспользуются: 87 799 уникальных масок на 103 699 строк. Валидация

4. Размеры изображений варьируются примерно от 154×205 до 1024×1024.

## Воспроизведение

Все команды выполняются из корня проекта.

1. Подготовить кэш масок (определяет, какие строки — позитивы, а какие — чистые):

```powershell
python -m src.prepare
```

2. Обучить модель. Скрипт сам разбивает данные по группам масок, добавляет
   негативы, контролирует лимит FLOPs и в конце подбирает порог по AIC:

```powershell
python -m src.train --epochs 10 --batch-size 8 --img-size 256 --name manip_unet_resnet34
```

Параметры запуска сохраняются в `outputs/checkpoints/<имя>_config.json`,
лучший чекпоинт — в `<имя>_best.pth`, подобранный порог — в `<имя>_threshold.json`.

3. Построить предсказания на тесте и собрать посылку:

```powershell
python -m src.predict `
  --checkpoint outputs/checkpoints/manip_unet_resnet34_best.pth `
  --threshold-json outputs/checkpoints/manip_unet_resnet34_threshold.json
```

На выходе `outputs/submission.zip` (содержит `submission.csv` и `predictions/`).

## Методология

- **Модель.** U-Net с энкодером ResNet34 (веса ImageNet). К RGB добавляется
  четвёртый канал — карта шума, выделенная обучаемой высокочастотной свёрткой.
  Следы инпейнта и вставки часто видны именно в шумовой составляющей.
- **Валидация.** Групповой сплит по `gt_path` (одинаковые маски не попадают в обе
  части), негативы из пустых масок и оригиналов `src/`. Метрика на валидации —
  тот же AIC Score, что и на лидерборде.
- **Порог.** Подбирается перебором на валидации по максимуму AIC, а не по
  значению 0.5 по умолчанию.

## Соответствие ограничениям

- **FLOPs.** Модель проверяется через `torch.utils.flop_counter.FlopCounterMode`
  (строгие FLOPs, как требует регламент) и не превышает 100 GFLOPs на изображение.
- **Данные.** Используются только предоставленные датасеты; тестовая выборка
  применяется исключительно для генерации финальных предсказаний.
- **Воспроизводимость.** Фиксируются сиды, параметры запуска сохраняются в JSON,
  обучение и инференс воспроизводятся командами выше и в `solution.ipynb`.
